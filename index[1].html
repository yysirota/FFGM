Scouting Lab

Independent expert opinions, disagreements and upside/downside research. Not crowd values.
How six experts become one number

Six votes: Dataroma, Draft Sharks, Twerski, Kev Wheeler, Justin Boone, and Nick Mariano are each weighted exactly 1/6 for players ranked by all six. When an expert omits a player, the available votes are reweighted equally and a confidence/coverage penalty applies: five 2.5%, four 6%, three 10%, two 15%, one 22%. Omission is not a zero. Dataroma uses raw 0–100 values; Draft Sharks uses published 3D values; Twerski Half-PPR values use 79 as the top reference; Boone Half-PPR and 2QB values use 101 as the baseline. Kev Wheeler supplied Standard-scoring rank-only rankings and Nick Mariano supplied Half-PPR ordinal/tier rankings, so their rank order is independently supplied but their numerical value distances are modeled onto common rank-to-value curves. Boone's direct 2QB prices contribute to Superflex QBs; the other five QB opinions are converted to a common Superflex rank-value curve using the prior approved historical calibration. TE adjustment is separate: without a required TE starter, Draft Sharks' ROS projected points locate the tight end among WR projections, and that estimated WR value receives an 80% share alongside 20% full six-expert TE consensus. With a TE slot, full TE consensus returns. No FantasyCalc or public-market input enters the model. These are modeled rankings, not validated championship probabilities.

Scenario Lab

Stress-test your own roster against injury, breakouts or regression. These are hypothetical scenarios—not forecasts or win probabilities.
How scenario analysis works

FFGM reoptimizes the team's actual starting slots after removing the selected player or applying the selected hypothetical change in model value. Existing bench players can move into the lineup. It does not estimate the likelihood of injuries, breakout events, weekly game results, or a statistically validated championship probability.

Private ESPN league? Use secure local export No passwords or cookies shared

An ESPN league ID alone cannot open a private league. A league member can download their own roster data while signed in to ESPN, then import that JSON here. The exporter runs inside ESPN, contacts ESPN only, and saves the data locally.

  1. On a computer, sign in to your private league at fantasy.espn.com.
  2. In Fantasy Football GM, enter the league ID and season above, then click Copy export script.
  3. On the ESPN league page, open the browser developer Console, inspect the script before pasting, then run it. It downloads a league JSON file.
  4. Return here and choose Import ESPN JSON below.
